### Hi, I'm Josh 👋

Founder & CEO of **[YOLO Labs](https://yololabs.ai)**. We're building **[YOLO Studio](https://yolo.studio)**: cloud development workspaces where autonomous coding agents build, test and ship real code in isolated sandboxes, right alongside you.

**Try it from your terminal:**

```sh
curl -fsSL https://yolostart.sh | sh
```

**Open source from YOLO Labs**

- [yolostart](https://github.com/yolo-labs-hq/yolostart): bootstrap a YOLO Studio workspace from your terminal
- [yolobridge](https://github.com/yolo-labs-hq/yolobridge): attach your local Claude Code or Codex to a workspace
- [yolo-cli](https://github.com/yolo-labs-hq/yolo-cli): the `yolo` CLI for workspaces, artifacts, apps and hosting
- [app-sdk](https://github.com/yolo-labs-hq/app-sdk): build tile-apps for YOLO Studio
- [flexdb](https://github.com/yolo-labs-hq/flexdb): MongoDB-like document store over Cloudflare D1
